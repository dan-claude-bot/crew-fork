## Why a round is needed

The last tree drilled on a real host is the `0.1.4-rc8` tag (`e3675e4`),
recorded in [`drills/0.1.4-rc8.md`](0.1.4-rc8.md): every declared leg green in
one round, on box 0.10.0. Between that tag and this candidate's base there are
**3 changes**, touching **28 files** outside the suites and docs, +1151 / −155
lines, in the CLI, the engine, the installer, the floor's server and the drill:

- **#792 (engine and CLI): box 0.11.0.** One door into a box
  (`shared/lib/box-entry.sh`: `box exec --user <agent>` on box 0.11.0 or
  later, the old entry on an older box, read from `box --version`); the mint
  drops `box new --user` and makes the tenant with `rig bootstrap <agent>-box
  --user <agent>`; the rig floor is `0.4.1`.
- **#822 (CLI, installer, floor, drill): crew as one service per machine.**
  `sudo crew service setup` makes the `crew` account and group, the
  `box grant --service crew --share crew` with caps, a sudoers rule for the
  group, `/etc/crew/service.conf`, the floor unit and the tick, restart and
  reset timers; fleets and state live under `/var/lib/crew`. Every other verb
  re-runs as the account. Per-user mode is gone, and the floor reads only the
  service's index. The drill gains the declared leg `service`
  (`drill/rehearsal-service.sh`), before `teardown`.
- **#818 (drill):** the closing teardown line names `--box crew-drill-floor`
  when that box stands.

The engine inside the boxes changes only in how a box is entered and minted
(`box-entry.sh`, `box-mint.sh`, `platform.sh`, `version-skew.sh`); the service
model is host-side. Both are read on a real host for the first time here, and
this is the first round on a box 0.11.0 host.

  candidate.

  ran on box 0.10.0; this round is the first on box 0.11.0, which is the point
  of the candidate.
- **Every leg green, browser included, in one round:** preflight must print no
  `the browser leg will read INCOMPLETE` line.

  operator running the round), systemd and box 0.11.0; without any one of them
  the leg reads `skip`, naming it, and the round reads INCOMPLETE. It stands
  the service up under scratch names only (account and group `crew-drill-svc`,
  `/etc/crew-drill-svc`, `/var/lib/crew-drill-svc`, units `crew-drill-svc-*`,
  the tree under `/opt/crew-drill-svc`), so a real `crew` service on the host
  is never touched, and tears it down with `--purge`.
- **`--creds gh:<name>` is required** for `floor-provision`, as on rc8.
- **`--fast` is never cited.** Its summary opens `## TIER: fast`
