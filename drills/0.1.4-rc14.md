  (`shared/lib/box-entry.sh`: `box exec --user <agent>` on box 0.11.0 or
  later, the old entry on an older box, read from `box --version`). The mint

  --user <agent>`. The rig floor is `0.4.1`.
- **#822 (CLI, installer, floor, drill): crew as one service per machine.**
  `sudo crew service setup` makes the `crew` account and group, the
  `box grant --service crew --share crew` with caps, a sudoers rule for the
  group, `/etc/crew/service.conf`, the floor unit, and the tick, restart and
  reset timers. Fleets and state live under `/var/lib/crew`. Every other verb
  re-runs as the account, and per-user mode is gone. The drill gains the

  leg's node, npm, Chromium and playwright-core. It never replaces an
  installed box, refuses inside a box, and the summary names the box.
- **#828 (drill): the round keeps its own credential pool.**
  `~/.config/crew-drill/credentials` (`drill/creds.sh`), used unless
  `CREW_CREDENTIALS_DIR` is set. Missing `--creds` entries, and the Telegram
  chat, are asked for on the terminal. Without a terminal, the round refuses
  and prints `drill/creds.sh …`. The floor's workspaces test also waits for a

- **#832 (engine): the rc11 round's finding.** The door into a box retries a

  box's own error, instead of reading it as a box with no user.

  - #835: `--creds` takes two `gh:` entries, used by case. The first logs the

  - #838: the armed app pass serves its own fleet definition

  - #839: `box_down_settled` (wait for the boot, stop, retry once) is used by

- **#843 (drill): the rc13 round's finding.** Before the roles mint in
  parallel, the round warms incus's per-remote image cache (one
  `incus image list <remote>:` per simplestreams remote), so first launches on

The engine inside the boxes changes in how a box is entered and minted, and in

has passwordless sudo), from a local checkout **at the published tag**:

    git clone --branch 0.1.4-rc14 git@github.com:heavy-duty/crew.git ~/Projects/crew-rc14

    runbooks/drill-host/drillhost.sh reset        # or `up`, the first time
    runbooks/drill-host/drillhost.sh run crew --from ~/Projects/crew-rc14 -- \
      --parallel --creds gh:<box account>,gh:<round account>,agent:<name>,tg:<name>

  the round with `--tree`, so nothing is fetched inside it. The summary's

**The restart rule (#753, 2026-11-24).** A defect found during the week is
fixed on `main` as the next candidate, which replaces the running one on both
fleets. The seven days continue for a fix that leaves alone what runs inside
the boxes (docs, tests, the drill, host-side CLI or floor, the installer). They
restart for an engine change: `shared/bin/`, `shared/lib/` outside
`shared/lib/host/`, `shared/conf/` or `shared/prompts/`. The record names
which case each fix was, and a fix touching both restarts the clock.

If the round or the run finds a defect, the fix lands on `main`
(`0.1.4-rc15-dev`) and the next candidate is `0.1.4-rc15`. If it holds,
`0.1.4` is promoted stable from this candidate, by stamps only. A final may
differ from its last candidate by stamps only.
