### Added

- The roster is editable from the floor: `GET /api/roster` reads `fleet.roster` as it is on disk (with an etag) and `roster-set` writes it — validated line by line, refused if the file moved since, every comment kept where it was, atomically, journalled in `.roster-journal.log` (#764).
- A **Roster** overlay beside **Registries**: one row per box (name, agent, roles, from), add / remove / save, each row's standing read off the poll; a new line becomes a box with `crew up` on the host, a removed line's box is left alone (#764).
