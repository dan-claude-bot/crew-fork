### Added

- The roster is editable from the floor: `GET /api/roster` reads `fleet.roster` as it is on disk (with an etag) and `roster-set` writes it — validated line by line, atomically, journalled in `.roster-journal.log` (#764).
- A save is refused `409` if the file moved since the editor opened it, checked again on the bytes the write is built from; every comment is kept where it was, and a line's roles in the order it was written (#764).
- A **Roster** overlay beside **Registries**: one row per box (name, agent, roles, from), add / remove / save, each row's standing read off the poll; a new line becomes a box with `crew up` on the host, a removed line's box is left alone (#764).
