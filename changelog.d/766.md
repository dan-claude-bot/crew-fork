### Added

- Floor actions are claimed while in flight: a box action holds its box and a fleet action the fleet, so a second click, tab or operator is refused `409 busy` naming the first, and nothing fires twice (#766).
- `GET /api/actions` publishes what is in flight, with each action's step and the fleet action's progress, so every tab disables and spins the same controls (#766).
- On the page, a held control is visibly disabled, the one doing the work spins, the status line names the step and counts its seconds, and a fleet action draws a progress bar (#766).
