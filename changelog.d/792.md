### Changed

- Box 0.11.0 support. crew enters a box with `box exec --user <agent>` on box 0.11.0 and later, which enters as root otherwise. Older box keeps today's door. The mode is read once from `box --version`, and an unreadable version is refused (#792).
- On box 0.11.0, the mint no longer passes `box new --user`. `rig bootstrap <agent>-box --user <agent>` creates the tenant instead, and the mint refuses if that user is missing afterwards. crew now declares rig 0.4.1 (#792).
- Printed `box shell` hints and the floor's copied shell command name `--user <agent>` on box 0.11.0. The drill records the box version and entry mode with each round (#792).
