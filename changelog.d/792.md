### Changed

- Box 0.11.0 support: crew reads `box --version` once and, on 0.11.0 or later, enters every box as its roster agent with `box exec --user <agent>`; older boxes are entered as before. An unreadable version refuses with exit 2 (#792).
- On box 0.11.0 or later, `crew new` mints without `--user` and refuses to enter a box before rig has converged it (#792).
- Printed hints and the floor's copied command read `box shell --user <agent> <box>` on box 0.11.0 or later, and the drill records which entry mode it ran in (#792).
