### Added

- A member's credentials are settable and never readable: `crew login <box> gh|agent [<kind>]` reads a token or key on stdin, and the floor's `credentials-set` and its **Credentials** overlay run the same shell (#765).
- Each agent profile declares the kinds the host may set (`AGENT_CRED_KINDS`): a setup-token or API key exported from `~/.config/crew/credentials.env`, a login's file pasted whole, or codex's own `login --with-api-key` (#765).
- The secret travels only as stdin into the box and lands 0600 where its CLI reads it; the reply is the box's verdict, and `.credentials-journal.log` records who set which kind, never the value (#765).
- The weekly reset carries a member's live credentials across the restore, through the host's memory and never its disk, so one set or rotated since the checkpoint is not rolled back (#765).
